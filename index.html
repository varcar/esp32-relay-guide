How it works

The ESP32 joins your Wi-Fi network and hosts its own tiny website. Your phone sends an ON/OFF request to the ESP32, which changes the relay's control pin.

📱
1. Tap

Open the ESP32's local IP address and press ON or OFF.

📶
2. ESP32 receives it

The built-in web server reads the command over Wi-Fi.

⚡
3. Relay switches

GPIO 26 tells the relay module to switch its output contacts.

Local network only: This build works when your phone and ESP32 can reach each other on the same Wi-Fi/LAN. It does not provide worldwide access. For that, use a secure cloud service or VPN.

Wiring the relay

For a common 3-pin module labeled VCC, GND, IN. The exact VCC connection depends on your particular relay module's rated supply voltage.

Relay pinConnect to
INESP32 GPIO 26
GNDESP32 GND (common ground)
VCCCorrect supply for your module (3.3V or 5V as specified)
Use a low-voltage test load only. Household AC/mains wiring can cause shock or fire. If controlling a fan, bulb or other mains appliance, use a properly enclosed, rated and professionally wired solution.

Let's build it

The entire dashboard runs from one Arduino sketch. You don't need to host a separate website for the controller.

Install Arduino IDE + ESP32 board support

Install Arduino IDE, then add the ESP32 board package using Boards Manager.

Download the firmware

Download the .ino file below and open it in Arduino IDE.

↓ ESP32_Relay_Guide.ino

Add your Wi-Fi credentials

Replace these placeholders in the downloaded sketch. Use a 2.4 GHz Wi-Fi network that your ESP32 supports.

const char* WIFI_SSID = "YOUR_WIFI_NAME";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";

Keep this private: Never upload your personalized sketch with real Wi-Fi credentials to a public GitHub repo.

Upload to ESP32

Choose your ESP32 board and COM port in Arduino IDE, then click Upload. If it fails at “Connecting…”, press and hold BOOT while the upload starts, then release it once writing begins.

Get the ESP32 IP address

Open Serial Monitor → 115200 baud. Once Wi-Fi connects you'll see a line like:

Open http://192.168.1.105

Your IP address will likely be different.

Open the dashboard on your phone

On the same reachable Wi-Fi network, open the printed address in your browser. Make sure the URL starts with http://, not https://. Tap ON or OFF and listen for the relay switching.

Common issues

Dashboard says “Refused to connect” on my phone

Use the exact http:// URL printed in Serial Monitor. HTTPS won't work with this simple server. If it still fails, ensure both devices can reach each other on the network; check router client isolation.

Dashboard says ON but the relay doesn't switch

First verify the relay's rated supply voltage, shared ground, and GPIO26 connection. The default code assumes an active-LOW module. For active-HIGH boards, change RELAY_ACTIVE_LOW to false. Some 5V relay modules cannot be driven reliably by a 3.3V GPIO and need suitable interface circuitry.

Relay turns ON immediately at boot

Some modules react to floating pins during startup, and some are active-HIGH rather than active-LOW. Verify your module's input type, switch polarity setting in the code, and use a suitable hardware default-off driver if unexpected activation is unsafe.

ESP32 keeps rebooting or freezes when the relay clicks

The relay coil may be drawing too much current or introducing electrical noise. Use a properly rated supply and appropriate relay driver/module rather than relying on a weak 3.3V output.

Can I control it from anywhere in the world?

Not using this version alone. This sketch intentionally runs a local HTTP server without authentication. Do not port-forward it to the public internet. For remote control, add a secure cloud dashboard or private VPN with authentication.
